# What only Aaron can do before the site is done

The build agents can land every slice in `docs/superpowers/plans/`; these are the things that still need Aaron's hands, his words or his accounts. Ordered by what blocks the most. Each line has a one-sentence nudge; the detailed how-to brief follows when the build starts (see "Briefs to come").

## 1. The things that gate a public launch

1. **The music.** Three Lee Rosevere tracks ship today under CC BY 4.0 (`public/audio/LICENSES.md`), which is legal and credited, but they are placeholders he never chose. Pick the tracks the site should play, confirm each licence allows web streaming with attribution (CC BY, CC0, or a purchased licence with the receipt kept), add every file to `public/audio/` with a row in `LICENSES.md` before it ships, keep each under about 5 MB (160 kbps MP3), and note that the wave's analysis levelling is tuned per track, so the builder re-checks the band pixel baseline after the swap. The visible credit in the band must name the artist and licence. Spotify link-out stays a follow-up (`docs/plans/waveform-spotify-handoff.md`).
2. **The copy that is still placeholder or his to rewrite.** `lib/content.ts` holds: the Who I am paragraph he dislikes; the section header names ("What I'm up to" does not read right to him); the Up to now items; the Connect labels; the band's ask and the "Not now" note (which stops promising the music follows); the mark card's words; the metrics stat labels and the two open figures (a LinkedIn number and one fun figure); the Talos row ("Open source, coming soon") and min/Max ("Live, link soon"); the Capital One case body and the IEEE case body; five photo captions marked TODO; the hero's first-visit lines. First person, sentence case, no em dashes. The creative director agent drafts these; Aaron signs off; a builder pastes them.
3. **The photos.** Seven placeholder SVGs (`photo-08` to `photo-14`; five are wired, `09` and `12` unreferenced) wait for real JPEGs. For each: a 3:4 crop for the Coil card and the modal size from `lib/photoSizes.ts`, first-person alt text, a caption, and EXIF stripped (location data in a phone photo is a real leak on a public site; `exiftool -all=` or export without metadata). Prefer AVIF or well-compressed JPEG under 300 KB.
4. **The GitHub token for the metrics.** A fine-grained personal access token with no repository access (the profile setting "private contributions" is on, so the calendar counts private work for any viewer), stored in Vercel as `GITHUB_CONTRIB_TOKEN` for production via `vercel env add`. Until then the committed snapshot serves and the day count stands still. Keep the profile setting on; if it is ever switched off, the live number drops to the public count overnight.
5. **The full Profa cut.** The trial cut stamps three glyphs (`*`, `;`, `@`), and the email in Connect has an `@`. The full Regular, Bold and Black from his asset pack go into `app/fonts/` under the gitignore allowlist (licence settled; do not raise it again); the loaders in `lib/fonts.ts` then drop the unicode-range carve-out.
6. **Brand assets he owns the access to.** Capital One (private Brandfolder) and IEEE (toolkit agreement) logos, the Talos mark, and the min/Max live URL; terms recorded in `public/work/logos/CREDITS.md`; mark versus wordmark per card is his call.
7. **His own hardware pass on the final local build**, both themes, trackpad and mouse, his phone (Safari: touch driver, no pill), and one Windows machine if he can borrow one (fonts and scrollbars differ). The loader on his Chrome in particular, since his port-3240 sighting never reproduced elsewhere.
8. **The merge calls and the push.** Every PR merges on his word in the master plan's order; production builds only from his push of `main`. He has placed a specific hold on go-live until the content pass is done; nothing above changes that.

## 2. The less obvious things

9. **The repo is part of the showcase.** `aaron-sulbaran/aaron-personal-portfolio` is public, and a PM who builds in public will have recruiters reading it. The README is stale (it still says `vercel deploy --prod --yes`, which agents are forbidden to run) and should describe the Coil, the labs-before-specs process and how to run it. Scan every doc for anything sensitive before it is tracked (vault paths, keys); AGENTS.md itself is gitignored on purpose.
10. **Social card.** `openGraph` and `twitter` metadata exist but there is no OG image. LinkedIn caches the first card it sees, so the image and description should be right before the first share; run the LinkedIn Post Inspector once after deploy to refresh its cache.
11. **Analytics.** The site has none. For a PM site the first visitor number is the one he will be asked about; `@vercel/analytics` is cookieless and one component in the layout. It is a small third-party surface and a Vercel feature, so it is a heads-up, not a blocker; his call.
12. **A resume link.** Most PM portfolios have one; this site does not. Decide whether Connect or the Menu panel carries a PDF (kept out of the repo's history if it has his phone number; a Vercel Blob or a link to a hosted file).
13. **Accessibility with a real screen reader.** VoiceOver on his Mac through the hero (the h1, the sr-only state with a scene), the book, the band controls and the mark's hold (which has a keyboard route but no hint), plus iOS "Reduce Motion" on his phone, which must render the poster and the book, never the scene.
14. **The holding page's retirement and the preview policy.** `vercel.json` skips preview builds; after launch, decide whether branch previews come back (they cost builds and would need the deployment-protection setting checked). The holding page stays reachable with `NEXT_PUBLIC_SITE_MODE=holding`.
15. **Backups of work that lives only on this laptop.** The `lab` branch (every lab, about forty commits) has never been pushed; `main` is 27 docs-only commits ahead of `origin/main`. A push of `main` triggers a production build (harmless: the default is still holding), and `lab` can go to GitHub as a plain branch. Both need his word because pushes are his.
16. **Time zone for the streak.** The streak counts days in UTC on the server; a late-night Austin commit lands on the next UTC day. Harmless for "60 days and counting", but worth knowing when the number looks off by one.
17. **The audio and autoplay rule.** Browsers block sound until a gesture; the band's "Play it" is that gesture, and the pill's state must never claim to be playing when the browser refused. The existing tests cover it; his hardware pass should include one tap on a phone.
18. **Case-page URLs.** `/work/[slug]` routes go live with the flip; any slug he renames later breaks a shared link, so the slugs in `lib/content.ts` should be the ones he is willing to keep.
19. **The 404 and error pages** carry copy too (`app/not-found.tsx`, `app/error.tsx`); read them once in his voice.
20. **The `/recruiting` dashboard** stays private behind `proxy.ts` and out of the sitemap; after launch, open it once with the key to confirm it still unlocks on the production build.
