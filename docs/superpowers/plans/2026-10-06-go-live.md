# Go-live Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** make the full site the default build so Aaron's push of `main` takes aaronsulbaran.com from the holding page to the first public edition, with the holding page still one environment variable away.

**Architecture:** `lib/holding.ts` decides the site mode at build time from `NEXT_PUBLIC_SITE_MODE`; today the default is holding and "full" opts in. This plan inverts the default (full unless the value is exactly "holding"), keeps every holding-mode code path intact, and fixes the one place that relied on the old default (the e2e holding build already sets the variable explicitly, the Playwright full project sets "full" explicitly, so only the unit test and the docs change). Metadata (`openGraph`, `twitter`, `metadataBase`) already exists in `app/layout.tsx` from `siteContent.meta` and is left alone unless Aaron supplies an OG image.

**Tech Stack:** Next 16.2, TypeScript strict, vitest, Playwright (builds both modes itself).

**Spec:** `docs/superpowers/plans/2026-10-06-first-public-edition.md` section 8; `AGENTS.md` Environment ("Going live = `NEXT_PUBLIC_SITE_MODE=full` on Vercel or flipping the default in `lib/holding.ts`").
