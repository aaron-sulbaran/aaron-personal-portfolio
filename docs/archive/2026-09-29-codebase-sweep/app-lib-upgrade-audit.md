## 2. Upgrade assessment

Target (Context7): Next 16.2.x is current; Next 16 uses React 19.2. Go directly to 16; a stop at 15 buys nothing (one async-API call site). Node >= 20.9, TS >= 5.1, Turbopack default for dev and build (no webpack config here). Codemod `npx @next/codemod@canary upgrade latest` covers package bumps, Turbopack config, `next-lint-to-eslint-cli`, `middleware-to-proxy`, `unstable_` removals, `next-async-request-api`. Not covered: `revalidateTag` second argument, `images.qualities`, React 19 type fixes (`npx codemod@latest react/19/migration-recipe`), ESLint 9, copy. Codemod covers roughly half the lines, under a third of the risk.

Touch points:
1. Async request APIs: no `next/headers` use anywhere. Only `app/work/[slug]/page.tsx`: line 12 `Params` type -> `Promise<{slug}>`; line 18 generateMetadata async + await; 19 and 34 `params.slug`; 31 default export async. Sync access fully removed in 16.
2. Fetch caching: every fetch is already explicit (`data.ts:50-57` revalidate 900 + tags; `vault-issues.ts:64-69, 79-84` and `refresh.ts:49-53` no-store). Pre-existing ambiguity: the recruiting page also renders no-store fetches, which likely makes it dynamic already; compare `next build` route tables before and after. Do not enable `cacheComponents` / `use cache`.
3. `revalidateTag` (real change): `edit/route.ts:34`, `refresh/route.ts:35`. Single-arg form is a TS error in 16; use `revalidateTag(tag, { expire: 0 })` at both sites to keep "next render is fresh".
4. Middleware -> `proxy.ts` (Node runtime only). `auth.ts` uses global Web Crypto, safe on Node 20+. `NextResponse.redirect/rewrite/cookies.set/headers.set` unchanged; `request.geo/ip` unused. Update the comment in `holding.ts`.
5. next/font: no breaking changes; confirm Turbopack's build-time Google font fetch works in the build environment.
6. next/image: 16 defaults `images.qualities` to `[75]`; `GlassTile.tsx:236` quality 88 and `PhotoModal.tsx:111` quality 90 would silently drop. Add `images: { qualities: [75, 88, 90] }`. Other 16 image defaults do not apply.
7. metadata/viewport already split; `generateMetadata` is the async-params item; theme-color meta mutation is low risk.
8. `redirect("/")` in holding mode unchanged; verify the six prerendered slugs in a local production build.
9. No removed React/Next APIs in use (no useFormState, forwardRef, next/router, next/head, next/dynamic, legacy image, runtime exports). createPortal, createContext, usePathname, useRouter fine.
10. @types/react 19 compile errors: `components/ArcIndex.tsx:20-27` six `RefObject<HTMLxElement>` props need `| null` (ArcIndex retires anyway); `components/BrandIcons.tsx:42` `JSX.Element` -> `React.JSX.Element`. Callback refs (MobileHome 666, UpToNowList 97, Popover 87, EditDialog 181) use block bodies, fine.
11. Peers: @gsap/react react >=17 OK; framer-motion 12.38 supports React 19; lucide OK; d3-sankey no React peer; zod, server-only fine; vitest independent; eslint-config-next must move to 16 (ESLint >= 9, flat config); TS OK; confirm the Vercel project Node version >= 20.9.
12. Lint: `next lint` removed; `package.json:9` and `.eslintrc.json` -> `eslint.config.mjs` (ESLint 9 flat, `eslint-config-next/core-web-vitals` + `/typescript`); `next build` no longer lints.
13. Tailwind: stay on 3.4. Tailwind 4 would change browser floor, border and ring defaults, move config to CSS, and make the 41 no-op alpha classes render (a design change). Not in this slice.
14. tsconfig will be rewritten on first run (adds `.next/dev/types/**`); review the diff. Add `images.qualities` to next.config; optionally `engines.node >=20.9`.
15. Stale copy: `lib/content.ts:526`, `README.md:3, 25-27`, AGENTS.md lines 89 and 173.
16. Runtime risk no tool checks: TileRing, MobileHome, Waveform, PlaybackPill, Menu, modals depend on effect timing, pinned ScrollTrigger, matchMedia contexts, the 520ms scrollReady delay, scroll locks, refresh recovery. StrictMode double-invokes are safe (idempotent refs). Needs a browser pass.

three.js: nothing installed. Vanilla three works on React 18 or 19; R3F 9 needs React 19. Needs `three` in dependencies, `@types/three` pinned to the matching minor, `transpilePackages: ['three']` in next.config (per R3F docs for Next 13.1+), a real dynamic `import()` from a Client Component after first paint (`next/dynamic({ ssr: false })` errors in Server Components), `lib/coilGeometry.ts` + test fits the vitest glob, addons from `three/addons/*`, dispose on teardown.

Risk ranked: (1) high, hero and motion runtime under React 19 + Next 16, browser-only check; (2) medium-high, lint pipeline; (3) medium, revalidateTag; (4) medium, image qualities; (5) medium, React 19 types; (6) medium-low, recruiting ISR vs dynamic ambiguity; (7) low-medium, proxy rename; (8) low, async params; (9) low, Turbopack, fonts, tsconfig, Node; (10) low, stale copy; deferred, Tailwind 4.

Estimate: bump + codemod + review 0.5 to 1h; params/revalidateTag/qualities 0.5h; types 0.5 to 1h; ESLint 9 1 to 1.5h; proxy 0.5h; local production build + route table + Turbopack/font check 0.5 to 1h; browser regression pass 2 to 4h; docs 0.5h. Total about 6 to 10 agent-hours, likely 8. Excludes three.js and Coil work. Verification is a local `pnpm build && pnpm start` under the coil build rules.
